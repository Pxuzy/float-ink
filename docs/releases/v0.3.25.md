# 悬浮画笔 v0.3.25

这一版重点带来 **悬浮球自由停留与可选靠边隐藏**，同时增加 **工具栏选色范围和实时预览**，并更新主界面配色、设置分类和首次授权体验。

适用于 Android 10 及以上手机和平板。以下为 v0.3.24 之后用户可感知的更新。

## 新功能

- **悬浮球自由停留**：拖到屏幕内合适的位置即可松手，不再强制吸附到左右边缘。
- **可选靠边隐藏**：在“设置 → 悬浮球”中选择“靠近边缘时自动隐藏到边界”。开启后，仅靠近左右边缘时贴边并按延迟隐藏；关闭后保持完整显示。原有隐藏开关和延迟设置继续保留。
- **工具栏选色范围**：可选择“仅当前工具”或“全部工具”。默认保持全部工具同步选色，也可以为每种工具单独保留颜色。
- **设置页实时预览**：调整工具栏按钮尺寸、工具顺序、显隐或颜色时，直接查看当前效果。
- **更新详情**：发现新版本后，可先查看版本名称、发布时间和更新说明，再选择下载或打开发布页。

## 优化

- **石墨蓝主界面**：启动按钮、工具选中态、滑块、复选框和单选框使用统一的浅蓝强调色，笔迹预览和颜色圆点仍显示实际画笔颜色。
- **设置分类更清楚**：按悬浮球、悬浮工具栏、历史画板、关于与更新分组，历史画板提供独立管理页面。
- **首次授权按步骤引导**：依次说明悬浮窗和通知权限。取消后可稍后继续；通知权限可暂不授予，有悬浮窗权限时仍可从首页启动服务。
- **应用名称统一**：主界面、系统通知和相关提示统一使用“悬浮画笔（FloatPen）”。
- 悬浮绘图面板保持原有灰度视觉，主应用主题调整不会改变画笔颜色。

## 修复

- 修复拖动悬浮球后，延迟自动隐藏不生效的问题。
- 修复屏幕变宽后，已经离开边缘的悬浮球仍保持隐藏状态的问题。
- 修复仅修改颜色时，悬浮球右下角色点未立即重绘的问题。
- 修复全局线宽调整后，正在运行的画板未立即收到新设置的问题。

## 下载与升级

- 下载下方 Assets 中的 **`float-ink-0.3.25.apk`**，或在旧正式版内进入“设置 → 软件更新”检查更新。
- 正式版沿用相同包名和发布签名，可由 Android 系统确认覆盖安装。Debug 测试包是独立应用，不会替换正式版。
- `float-ink-0.3.25.apk.sha256` 用于核对下载文件是否完整，无需安装。

## 验证范围

本版执行自动化测试与 APK 构建；正式包发布前校验包名、版本和签名。真实手机和平板的触摸手感、横竖屏、分屏、厂商后台策略与覆盖安装仍待设备验收，不等同于已验证所有机型。
