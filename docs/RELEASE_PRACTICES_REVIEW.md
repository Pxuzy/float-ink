## 推荐提交写法

```text
fix(permission): 拒绝通知授权后结束引导并允许启动悬浮球

- 原流程在拒绝回调中再次请求权限，可能造成重复弹窗
- 拒绝或取消后结束流程；仅在首页明确请求启动且已有悬浮窗权限时启动服务
- 补充 Android 13 拒绝、空结果、取消及正常启动回归测试
```

简单改字或版本号无需长篇正文。重要行为修改应写清触发条件、用户影响和已执行的验证。标题格式只帮助分类，正文中的因果与证据才便于排查和回退。

## 推荐版本说明结构

开头用一段话概括最值得更新的两三项变化，再列“新功能 / 优化 / 修复”。每条解释用户能做什么或在哪种操作下问题已解决；重大升级风险和操作方法单列。结尾给 APK 下载、最低 Android 版本、覆盖安装条件、已验证/未验证范围与差异链接。

ReadAny 的双语和多平台说明适合它的受众。悬浮画笔当前以中文 Android 用户为主，可以先保证中文说明准确，不必为了相似而增加未支持的平台或重复篇幅。
