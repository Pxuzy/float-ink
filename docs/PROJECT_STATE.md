## 项目定位

浮墨（FloatInk）是一个轻量、低干扰的 Android 悬浮屏幕讲解笔，面向手机和平板上的讲课、演示和远程指导场景。

核心流程：

```text
可拖动悬浮球
  → 点击进入透明全屏画板
  → 手指或手写笔绘制标注
  → 使用工具、颜色和撤销/清空操作
  → 点击退出
  → 清除本次临时笔迹并返回原 App
```

它不是截图编辑器，也不是云端白板产品。

## 当前产品边界

### 已确认

- 首发平台：Android 手机和平板
- 支持范围：Android 29+
- 技术栈：原生 Android / Kotlin / Gradle
- 绘制层出现时接管触摸，底层 App 不应响应绘图操作
- 退出绘图层后底层 App 恢复触摸
- 当前会话中的笔迹默认是临时的
- 不截图、不读取、不上传底层 App 内容
- 悬浮窗服务使用用户授予的系统权限
- 设备更新通过 GitHub Releases 的 APK 完成，不在设备上执行 `git pull`

### 明确不做

- iOS / iPad
- 截图、录屏、图像导出
- 云同步、登录和统计分析
- AccessibilityService、MediaProjection
- 相机、麦克风和广泛存储权限
- 完全静默的后台安装 APK
- 在没有真实验证的情况下宣称设备兼容

## 软件端更新钩子

- 软件检查 GitHub Releases 的 `latest` 正式版本，并只接受更高版本号。
- 下载完成后、启动系统安装器前校验 APK 包名、`versionCode` 和 FloatInk 正式签名证书 SHA-256。
- 校验失败不调用安装器，阻止错误包、降级包、未签名包和不同签名包破坏覆盖安装。
- 如果当前已安装版本不是正式签名包，提前提示用户备份数据、卸载旧包后再安装，避免系统安装器最后才报告签名冲突。

## 发布签名门禁

- Release 构建缺少签名环境时直接失败，不再允许生成可发布但未签名的 APK。
- GitHub Release 使用固定的 FloatInk 发布证书 SHA-256 校验，防止新旧版本无法覆盖安装。
