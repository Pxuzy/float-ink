## 我们正在做什么

做一个 Android 平板上的临时悬浮讲解笔。它不是截图编辑器，也不是白板产品。

核心体验：

```text
可拖动悬浮球 → 点击 → 透明全屏画板 → 手指/手写笔自由画线 → 点击退出 → 清空并回到原 App
```

## 已确认的产品决定

| 项目 | 决定 |
|---|---|
| 首发平台 | Android 手机和平板 |
| iPad | 首版不做 |
| 屏幕内容 | 不截图、不读取、不保存、不上传 |
| 绘制层 | 开启时接管触控，底层 App 暂不可操作 |
| 笔迹 | 临时存在，退出即清空 |
| 输入 | 默认手指和手写笔都可画 |
| 完整工具栏 | 后续再做，不属于 V0 |
| V0 | 悬浮球、透明画板、自由画线、退出清空 |
