## 项目定位

浮墨（FloatInk）是一个轻量、低干扰的 Android 悬浮屏幕讲解笔，面向手机和平板上的讲课、演示和远程指导场景。

核心流程：

```text
可拖动悬浮球
  → 点击进入透明全屏画板
  → 手指或手写笔绘制标注
  → 使用工具、颜色和撤销/清空操作
  → 点击退出
  → 清除本次临时笔迹并返回原 App
```

它不是截图编辑器，也不是云端白板产品。

## 当前产品边界

### 已确认

- 首发平台：Android 手机和平板
- 支持范围：Android 29+
- 技术栈：原生 Android / Kotlin / Gradle
- 绘制层出现时接管触摸，底层 App 不应响应绘图操作
- 退出绘图层后底层 App 恢复触摸
- 当前会话中的笔迹默认是临时的
- 不截图、不读取、不上传底层 App 内容
- 悬浮窗服务使用用户授予的系统权限
- 设备更新通过 GitHub Releases 的 APK 完成，不在设备上执行 `git pull`

### 明确不做

- iOS / iPad
- 截图、录屏、图像导出
- 云同步、登录和统计分析
- AccessibilityService、MediaProjection
- 相机、麦克风和广泛存储权限
- 完全静默的后台安装 APK
- 在没有真实验证的情况下宣称设备兼容

## v0.3.0 已实现

### 悬浮与绘图

- 悬浮球拖动、点击、长按和贴边
- 悬浮球自动隐藏、唤醒、透明度和隐藏延迟设置
- 透明全屏绘图覆盖层
- 手指和手写笔输入
- 画笔、直线、箭头、矩形、圆形
- 撤销、清空和退出
- 箭头头部比例调节
- 各绘图工具独立保存颜色和线宽
- 设置修改后向正在运行的悬浮层同步
- 已完成笔迹保留创建时的颜色和线宽

### 画板与图层

- 当前会话支持多个画板和图层

- 多个可见图层按层级合成
- 隐藏活动图层开始绘制时自动恢复可见
- 撤销和清空作用于当前图层
- 退出绘图层保留当前会话，停止服务时清除会话

### 设置与更新

- App 首页、画笔页和设置页三页导航
- 默认工具、颜色、线宽和箭头比例持久化
- 悬浮按钮透明度、自动隐藏和隐藏延迟持久化
- 悬浮工具栏启用/停用和排序
- GitHub Releases 更新检查、APK 下载和系统安装器交接
- Android 14+ 前台服务类型和通知权限适配

- 先读 `README.md`、本文件和 `docs/GOAL.md`
