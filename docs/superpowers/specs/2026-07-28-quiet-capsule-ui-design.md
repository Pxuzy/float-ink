# FloatInk 静默胶囊 UI 设计

## 目标

在不改变绘图数据、手势、工具顺序和持久化语义的前提下，把 FloatInk 主界面、悬浮工具栏和颜色编辑统一为低干扰的“静默胶囊”视觉，并确保 RGB 精确输入能够可靠调出系统数字键盘。

## 已确认方向

- 主方向：A 静默胶囊。
- 辅助语言：吸收 C 纸面工具的秩序感，包括更清晰的分区、细边框、较低圆角和克制留白。
- 不采用浅色悬浮工具栏。悬浮层继续使用深色中性表面，保证叠加在浅色或深色 App 上都有可见性。
- 不采用 B 的常驻侧轨。侧轨会压缩手机内容宽度，平板优势不足以抵消手机成本。

## 用户体验原则

1. 绘图是第一任务，控件不抢占内容注意力。
2. 高频操作一层到达：颜色、工具、撤销、清空、退出。
3. 精确输入必须像普通 Android 表单一样可编辑，点击 RGB 数值立即出现系统数字键盘。
4. 颜色只用于表达当前墨色，不用于装饰工具图标或大面积背景。
5. 每个交互控件保留至少 48dp 触控区域，视觉图标可小于触控区域。
6. 所有弹层在窄屏、横屏、分屏和键盘出现后仍能退出、保存或取消。

## 信息架构

### App 主界面

保留固定底部导航：`首页 / 画笔 / 设置`。

- 首页：服务状态、主启动/停止操作、当前画笔摘要。
- 画笔：默认样式、当前工具、颜色与线宽、实时预览。
- 设置：悬浮按钮行为、工具栏布局、历史画板、软件更新。

减少说明性副标题和重复卡片。页面分区使用无框标题和带细边框的功能表面，不嵌套卡片。

### 悬浮工具栏

维持单行可拖动结构：

```text
[拖动] [画板] [颜色] [横向工具区…………] [撤销] [清空] [退出]
```

- 颜色放在画板入口之后、绘图工具之前，作为工具样式的视觉前缀。
- 工具区可横向滚动。
- 撤销、清空、退出固定在末端，任何宽度下都不得滚走。
- 工具图标为统一的白色线性图标；当前工具使用白色描边和低透明填充；只有颜色点显示真实墨色。
- 普通宽度下显示必要标签；紧凑宽度下隐藏标签但保留 `contentDescription`。

## 颜色体验

### 颜色入口与面板

点击颜色点展开紧凑面板，锚定在工具栏上方；空间不足时放到下方。颜色面板与画板面板、更多工具面板互斥。

第一层：

- 内置色和自定义色组成 4 列色板。
- 最近颜色单独一行。
- `+` 使用原生加号图标，进入精确编辑。

第二层精确编辑：

- HSV 取色区。
- 当前颜色预览。
- 透明度。
- HEX 输入。
- RGB 三通道输入。
- 取消、保存。

App 和悬浮层共用同一输入、校验和颜色转换契约，避免两个编辑器行为不同。

### RGB 输入契约

- RGB 拆为 `R`、`G`、`B` 三个独立 `EditText`。
- 每个输入框只允许十进制整数，范围 `0..255`，使用 `InputType.TYPE_CLASS_NUMBER`；不设置小数或符号 flag，不接受小数点和负号。
- 点击任一通道后请求焦点并调用 `InputMethodManager.showSoftInput()`；App 内使用 `WindowInsetsControllerCompat`/标准窗口焦点路径作为优先方式。
- HEX 使用文本键盘，接受 `#RRGGBB` 与 `#AARRGGBB`。
- 保存时以最后主动编辑的输入模式为准：HEX、RGB 或 HSV；无效值不关闭编辑器，直接在对应输入区域显示错误。
- RGB 输入为空、超过 255、包含非数字字符或通道不完整均拒绝保存。

## 悬浮层键盘焦点

当前绘图窗口使用 `FLAG_NOT_FOCUSABLE`，因此内部 `EditText` 不能可靠调出 IME。采用临时可聚焦窗口策略：

1. 打开精确颜色编辑器时，`DrawingOverlayView` 通过回调请求 `OverlayService` 切换绘图窗口为可聚焦。
2. 服务移除 `FLAG_NOT_FOCUSABLE` 和 `FLAG_ALT_FOCUSABLE_IM`，保留 `FLAG_LAYOUT_IN_SCREEN`，设置 `SOFT_INPUT_ADJUST_RESIZE` 作为兼容路径，再 `updateViewLayout()`；不得增加 `FLAG_NOT_TOUCH_MODAL`，全屏绘图窗口仍须截获全部触摸。
3. RGB 输入框在收到 `onWindowFocusChanged(true)` 后请求控件焦点，再通过 `InputMethodManager.showSoftInput(..., SHOW_IMPLICIT)` 显示数字键盘；不得在窗口尚未聚焦时只调用一次后假定成功。
4. API 30+ 同时监听 `WindowInsets.Type.ime()`，按实际 IME inset 收缩或滚动颜色编辑区；`SOFT_INPUT_ADJUST_RESIZE` 仅作为旧系统与 OEM 兼容路径，不作为唯一布局保证。
5. 保存、取消、系统返回键、关闭颜色面板、切换互斥面板、配置变化、退出绘图、服务销毁或发生异常时，先隐藏键盘和清理输入焦点，再幂等恢复 `FLAG_NOT_FOCUSABLE` 与默认 `softInputMode`。
6. 恢复后画板继续消费触摸，底层 App 不得收到绘图区域触摸。
7. 焦点切换或 `updateViewLayout()` 失败时立即执行同一恢复函数；保留可退出的编辑器并显示错误，不让窗口停留在不可绘图的半状态。

`OverlayService` 是唯一允许修改 `WindowManager.LayoutParams` 的所有者；服务持有当前附着窗口的同一个参数实例，不用新建窗口或移除重加 View 来切换焦点。`DrawingOverlayView` 只发送“进入/退出文本输入模式”请求，退出请求必须可重复调用。

## 视觉系统

### 色彩

- App 背景：`#0B0F14`
- 一级表面：`#121820`
- 二级表面：`#18212B`
- 工具栏/弹层：约 `rgba(12,16,21,0.93)`
- 主文字：`#F7F9FB`
- 次文字：`#91A0B2`
- 边框：白色 12%–24%
- 强调色：用户当前墨色；仅在可读性不足时使用中性白色作为主按钮颜色。

不使用渐变、彩色工具图标、紫色主色、玻璃模糊或大面积高饱和背景。

### 圆角与间距

- 小控件：6dp
- 面板/工具栏：8dp
- 大型对话或页面功能表面：8dp
- 触控槽：48dp
- 基础间距：4dp；常用间距为 8/12/16/24dp
- 页面水平边距：16dp；平板内容区设置最大宽度，不拉伸到全屏

### 字体层级

使用 Android 系统可用的中文无衬线字体，避免额外字体依赖：

- 页面标题：24sp，粗体
- 分区标题：14sp，中粗体
- 正文/控件：14–15sp
- 辅助信息：12–13sp

文字不使用负字距，不随视口宽度缩放。

## 响应式规则

- 220dp 极窄窗口：隐藏工具标签，保留颜色、一个当前工具和固定操作；面板宽度不超过可用宽度。
- 320dp 手机：单行工具栏，工具区滚动；精确编辑器使用可滚动内容。
- 横屏：缩短 HSV 区高度；键盘出现后保存/取消仍可见或可滚动到达。
- 600dp+ 平板：App 页面内容宽度封顶；悬浮工具栏不无意义拉长。
- 字体放大：文本行使用 `WRAP_CONTENT + minHeight`，不得依赖固定高度截字。

## 状态与错误处理

- 当前颜色、当前工具、服务状态必须具有非颜色的文本或图标提示。
- RGB 错误显示在输入组内，不只使用 Toast。
- 自定义颜色保存后立即更新 App 色板、悬浮色板、当前颜色点、当前工具样式和下一笔；既有笔迹保持原颜色。
- 删除当前自定义色时回退到内置默认色并持久化。
- 配置变化重建工具栏时，保留普通面板类型；若正在精确输入，则先安全关闭键盘并恢复非聚焦状态，再恢复到颜色面板第一层，不自动重新聚焦输入框，避免旋转后焦点泄漏和键盘反复弹出。

## 测试与验收

### 自动化

- App 自定义颜色编辑器包含 ScrollView、HSV、透明度、HEX、三个 RGB 数字输入、取消和保存。
- 三个 RGB 输入的 `inputType` 为数字，边界 `0`、`255` 可保存，`256`、空值和非数字拒绝。
- 点击 App RGB 输入会请求焦点；保存使用最后编辑模式。
- 悬浮颜色入口位于工具区之前，固定操作仍位于末端。
- 打开悬浮 RGB 编辑器触发进入文本输入模式；保存、取消、系统返回、互斥面板切换、配置变化、关闭和退出均触发同一个幂等恢复函数。
- 聚焦模式移除 `FLAG_NOT_FOCUSABLE`/`FLAG_ALT_FOCUSABLE_IM`，但不增加 `FLAG_NOT_TOUCH_MODAL`；恢复模式重新包含 `FLAG_NOT_FOCUSABLE`。
- API 30+ 的 IME inset 到达时，RGB 输入与保存/取消操作仍在可滚动区域内可达。
- 220dp、320dp、横屏和 700dp 结构测试通过。
- 现有绘图、画板/图层、触摸、服务、持久化和历史会话测试全部通过。

### 真实设备

- 点击 App 内 R/G/B 任一输入框，系统数字键盘立即出现。
- 点击悬浮层 R/G/B 任一输入框，系统数字键盘立即出现，面板不被完全遮挡。
- 键盘返回、保存、取消、旋转、退出后，画板恢复绘图且底层 App 不接收触摸。
- 在浅色网页、深色视频、竖屏、横屏、分屏、手机和平板检查工具栏对比度、遮挡和拖动。
